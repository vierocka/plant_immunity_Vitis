# ROADMAP: de_novo_assembly

**AIM.** De novo assembly and characterization of reads that failed to
map to the PN40024 v4 reference, to clarify the likely composition of
the unmapped fraction (see `README.md`).

**MOTIVATION.** Not part of the manuscript's main Methods/Results; kept
here as a descriptive QC check supporting the interpretation of
mapping-rate/batch differences discussed elsewhere in this repo (see
`01_QC_and_Filtering/`).

## Contents

```
scripts/   numbered 01-12, chronological pipeline order (see README.md)
```

No intermediate data files are kept here (contigs, predicted proteins,
BLAST/MCL output, count matrices) — the working pipeline output lives
outside this repo (`~/Dropbox/MendelUni_Vinselect/spades/unmapped/`).
